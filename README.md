# MyDiary 📝

A personal diary web application built with **Java and Spring Boot**.

### 🚀 Features

* User registration, login, and logout
* Authentication and authorization using Spring Security
* Secure password hashing with BCrypt
* User-specific diary entries
* CRUD operations for diary entries

### 🛠️ Tech Stack

* Java
* Spring Boot
* Spring Security
* Spring Data JPA & Hibernate
* MySQL
* Thymeleaf, HTML & CSS

### 🎯 Purpose

Built to strengthen my understanding of **backend development, authentication, authorization, and database integration** using Spring Boot.
